# Diese Library: VeluxKLF200  

- Diese Library dient zur Anbindung des Velux KLF200 Gateway, an die Software IP-Symcon. Sie stellt die notwendigen Module und Funktionen bereit, um spezielle io-homecontrol Geräte in IP-Symcon zu integrieren und zu steuern.
- Die Library ist so konzipiert, dass sie leicht erweiterbar ist, um fehlende Abschnitte bei der Erweiterung der KLF 200 API zu ergänzen.

  - KLF 200 API Dokument unter  @docs/
